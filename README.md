# 🍽️ Royal Restaurant — Full-Stack Restaurant Management System

> A complete restaurant management platform connecting customers, orders, payments, kitchen operations, food management, delivery, and restaurant administration in one system.

![Restaurant Management System](screenshots/home.png)

## 🚀 Overview

Royal Restaurant is a full-stack web application built with **HTML, CSS, JavaScript, Node.js, Express.js and MySQL**.  
It provides separate customer and staff workflows for managing the complete restaurant ordering and operations process.

## ✨ Key Features

### 👤 Customer
- 🏠 Restaurant Home
- 📝 Customer Registration
- 🍴 Menu & Food Categories
- 🛒 Cart / My Order
- 💳 Payment Flow
- 📦 Order Placement
- 🎙️ Voice Assistant

### 👨‍💼 Staff Management
- 📊 Dashboard
- 📦 Order Management
- 🍔 Food & Inventory
- 👨‍🍳 Cooking / Kitchen
- 🧹 Cleaning
- 🚚 Delivery
- 📈 Restaurant Management
